# V2.1 — Compaction Spec

## 5 Tools

### symapse_ask
**Question:** "What should I know before working on X?"

Internal routing:
1. `classifyIntent(description)` → config/source/understanding
2. If config → return configFiles + docFiles, skip graph
3. `clarifyRequest(description)` → confidence, missing decisions, questions
4. `findWhereToIntegrate(description)` → architectural targets
5. `getConventions()` → naming patterns per module

Output: intent, confidence, questions, related systems, recommended modules, conventions summary

### symapse_find
**Question:** "Where is X and what does it touch?"

Internal routing:
1. If query is a single identifier → `getImpact(name)` first
2. If impact found → return location + direct callers/callees + impacted files
3. If impact not found → `listFunctions(query)` → search results
4. If no query → `getChanges()` → recent changes

Output: symbol location + impact OR search results OR change log

### symapse_map
**Question:** "Show me the shape of this repo / this feature."

Internal routing:
1. If description provided → `getContextFiles(description)` → must-read files
2. If no description → `getArchitectureSummary()` → domains, critical nodes, flows
3. If `overlap` flag → `findSemanticOverlaps()` appended

Output: file list with reasons OR domain summary OR overlaps

### symapse_audit
**Question:** "What's wrong, unused, or duplicated?"

Internal routing:
1. `getDeadCodeCandidates()` → scored dead code list
2. `findSemanticOverlaps()` → overlapping function pairs
3. `getConventions()` → naming consistency report

Output: dead code + duplicates + convention violations

### symapse_health
**Question:** "What's the state of the index?"

Internal routing:
1. `getStatus()` → file count, symbol count, edge count, top files
2. If `--refresh` → `refreshIndex()` → updated status
3. If `--watch` (future) → file watcher with micro-incremental indexing

Output: index statistics + optional re-index trigger
